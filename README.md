# 小账本（Ledger）

完全本地运行、隐私优先的个人记账工具。多账户（微信零钱 / 支付宝 / 多张银行卡 / 现金）、微信/支付宝/银行流水多源导入、**跨源去重**（同一笔绑卡消费只计一次）、数据 100% 存本机浏览器。

## 隐私承诺

- **零网络请求**：不加载任何外部资源（无 CDN / 无字体 / 无图表库），无埋点、无统计上报，**断网可完整使用**。可在浏览器 DevTools → Network 面板验证。
- **数据仅存本机**：全部数据保存在本机浏览器的 IndexedDB，不上传任何服务器。
- **应用锁加密**：可选开启（PBKDF2 派生密钥 + AES-GCM 加密落盘）。⚠️ 密码不落盘、无法找回，**忘记密码 = 数据不可恢复**；开启前请先导出一份 JSON 备份。
- **数据永不锁定**：随时导出 JSON 全量备份 / CSV 明细（带 BOM，Excel 中文不乱码）。

## 快速开始

**方式一（推荐，macOS）**：双击 `start.command`（首次右键 → 打开），自动启动本地服务并打开浏览器。

**方式二（任意平台）**：

```bash
cd ledger
python3 -m http.server 8421
# 浏览器打开 http://localhost:8421
```

> 不建议直接双击 `index.html`（file:// 打开）：部分浏览器在 file:// 下限制 IndexedDB。若你使用的浏览器允许，应用会自动退化为 localStorage 存储，但更稳妥的方式是本地服务。

## 账单导出路径速查

| 渠道 | 路径 |
|------|------|
| 微信 | 我 → 服务 → 钱包 → 账单 → 右上角常见问题 → 下载账单 → 用于个人对账（邮箱收压缩包，解压后为 CSV） |
| 支付宝 | 我的 → 账单 → 右上角 … → 开具交易流水证明 → 用于个人对账 |
| 招商银行 | App → 我的 → 账户总览 → 交易流水 → 导出（邮箱接收 CSV） |
| 中国银行 | App → 账户 → 交易明细 → 更多 → 导出流水 |

> 收到 XLSX/PDF？先在 Excel/Numbers 中**另存为 CSV** 再导入。

## 推荐使用节奏

平时随手手动记几笔；每周或每月批量导出三个账单导入。去重引擎保证"手动 + 导入"和"渠道 + 银行"两边合一、不算两次。

## 数据安全提醒（重要）

- 浏览器**「清除站点数据」/「清除浏览器数据」会清空 IndexedDB**，请定期（建议每月）在「我的 → 导出 JSON 备份」留存备份文件。
- 换电脑/换浏览器：旧环境导出 JSON → 新环境「我的 → 从备份恢复」。
- 开启应用锁前，务必先导出一份明文备份并牢记密码。

## 常见问题

**Q：导入后统计偏高？** 检查是否同一天同金额被记两次——去重引擎会自动合并跨源高置信重复，低置信重复在导入向导第 4 步确认；误合并可在明细 → 交易详情 → 撤销合并。

**Q：CSV 打开乱码？** 本应用导出的 CSV 自带 BOM，Excel/Numbers 可直接打开；若你自己编辑后乱码，请以 UTF-8 保存。

**Q：导入失败会影响已有数据吗？** 不会。解析/映射/去重全部在内存向导中完成，只有最后一步「确认导入」才写入；任何失败都不阻塞手动记账。
