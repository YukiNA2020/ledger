## 2. 题目原文（对受测者的原话，不得临时改变题意）

页面加载完成后开始计时，受测者自行查看页面后回答以下四题：

1. 这本账当前的**净资产**是多少？
2. 这本账当前可用于投资的**可投资资产**是多少？（注意：题目问的是可投资资产，不是本月可新增的投资资金）
3. 当前**主要风险暴露**是哪一类资产（金额最大的一类）？
4. 如果本月有新增资金要投入，按这本账的建议，**优先方向**是什么？

判定口径：**四题全部正确 且 总耗时 ≤ 60 秒**才通过；页面加载用时单独记录，不充当理解时间；
过程中不给答案提示。

## 3. 计时流程（主测人执行）

1. 运行 `python3 docs/evidence/phase6/run_6e3_demo.py <端口>`，确认打印出「演示前置失败」以外的标准答案表；
2. 让受测者坐到浏览器前，打开 `http://127.0.0.1:<端口>/`（受测者看不到本文件与答案表）；
3. 页面渲染完成后按下秒表开始计时（页面加载用时 = 打开到渲染完成，另记）；
4. 受测者自行查看页面，口头回答四题，主测人逐字记录回答原文，不纠正、不提示；
5. 第四题答完即停表，记录总耗时；按 §4 判定表逐题判定；
6. 填写 §5 记录表，把本文件顶部状态改为实际结果；失败时按 §6 处理。
